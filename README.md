# Fitness Tracker & Workout Guide

A desktop fitness tracker and workout guide built with **C++** and **Qt**.  
Tracks user fitness routines, provides exercise videos, diet plans, and BMI calculation.

## Features
- User Signup & Login (Password hashing for security)
- Daily fitness checklist & workout history stored securely in binary files
- Workout guide with timers, recommended reps/sets, and difficulty levels (Beginner, Intermediate, Expert)
- 4 muscle groups: Arms, Legs, Chest, Shoulders
- Two static diet plans: Gain & Lose weight
- BMI calculator for personalized fitness goals
- Front-end & back-end fully implemented in Qt

## Tech Stack
- C++ / Qt
- SQLite (or MySQL for earlier version)
- Binary file handling for secure storage
- Video integration for exercise demonstrations
